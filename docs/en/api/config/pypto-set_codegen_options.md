# pypto.set\_codegen\_options

<!-- md-trans-meta sourceCommit=d92d51ac286ac6802735f52dae2fade039bbc9b3 translatedAt=2026-08-18T12:07:32.284Z pushedAt=2026-08-26T09:10:38.129Z -->

## Applicable Products

- Ascend 950PR/Ascend 950DT: Supported
- Atlas A3 training products/Atlas A3 inference products: Supported
- Atlas A2 training products/Atlas A2 inference products: Supported

## Description

Sets the options for codegen.

## Prototype

```python
set_codegen_options(*,
                    support_dynamic_aligned: bool = None,
                    enable_pmu_trace: bool = None) -> None
```

## Parameters

| Parameter | Input/Output | Description |
|-----------|--------------|-------------|
| **support_dynamic_aligned** | Input | Meaning: Whether to support dynamic shape. <br> Description: <br> When the value is **True**, the device-side binary generated by the operator can support dynamic shape aligned scenarios. <br> When the value is **False**, the device-side binary generated by the operator supports only dynamic shape unaligned scenarios. <br> Type: bool <br> Value range: {**True**, **False**} <br> Default value: **False** (If the operator is confirmed to support dynamic shape and all last axes of the shape are aligned, you can try enabling it to check whether there is a performance gain). <br> Affected Pass scope: None, only affects the CodeGen module in generating device-side target code. |
| **enable_pmu_trace** | Input | Meaning: Whether to enable PMU Trace. <br> Description: <br> When the value is **True**, CodeGen inserts `bisheng::cce::mark_stamp` markers at the beginning and end of the CCE code corresponding to each leaf function, and assigns a PMU ID to each, for locating the corresponding kernel in the in-core pipeline. At runtime, `msprof --instr-profiling=on` must be used for instruction-level collection. <br> When the value is **False**, no PMU markers are inserted. <br> Type: bool <br> Value range: {**True**, **False**} <br> Default value: **False** <br> Affected Pass scope: None, only affects the CodeGen module in generating device-side target code. |

## Return Value

**void**: The **Set** method has no return value. The setting takes effect immediately upon successful execution.

## Constraints

The effect of the **support_dynamic_aligned** option will be optimized through the Pass inference mechanism in the future, so users do not need to set it manually and it will be deprecated. Users are advised to use it with caution.

**enable_pmu_trace** is currently supported only on Ascend 950PR/Ascend 950DT, supports only single-operator collection (the whole-network scenario is not supported), and can collect data from at most 6 cores. For more usage instructions, see [Performance Tuning Guide](../../tutorials/debug/performance.md#pmu-trace).

## Example

```python
pypto.set_codegen_options(support_dynamic_aligned=True)
pypto.set_codegen_options(enable_pmu_trace=True)
```
